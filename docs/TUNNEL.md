# Private tunnel and access control

## What you get

`npm run dev:tunnel` starts the app plus a Cloudflare quick tunnel (`*.trycloudflare.com`, no account). The URL is
random and public, so **the app protects itself**:

- every `/api` request and the sync WebSocket require `ACCESS_TOKEN` (32+ random bytes generated by setup);
- the link you receive is `https://<random>.trycloudflare.com/?t=<token>`; the frontend sends the token once to
  `/api/auth/session`, gets an HttpOnly, SameSite=Lax (Secure over https) cookie, and removes `?t=` from the URL;
- requests from this machine skip the token (`LOCAL_TRUST=true`); tunnel traffic carries Cloudflare headers and a
  non-local original host (stamped by the Vite proxy), so it never counts as local;
- the backend and Vite listen on `127.0.0.1` only; ten wrong tokens in five minutes are rate limited.

## Delivery modes (`TUNNEL_NOTIFY_MODE` in `.env`)

| Mode | Pushes to your ntfy topic | Use when |
|---|---|---|
| `link` (default) | the full private link (with token) | you keep `NTFY_TOPIC` long, random and private |
| `url` | the bare URL; you paste the token yourself on the lock screen | you do not fully trust the topic |
| `off` | nothing; copy the link from the terminal | strictest |

Anyone who can read your ntfy topic can read the link, so treat the topic like a password (setup generates a random
one). Self-hosting ntfy: set `NTFY_SERVER`.

## Verify

```bash
npm run dev:tunnel            # in one terminal
npm run doctor -- --sweep --tunnel   # in another: expects 401 without a token and 200 with it
```

## Rotate the token

Delete the `ACCESS_TOKEN=` value in `.env`, run `npm run setup -- --skip-install`, restart. Old links and cookies stop
working.

## Alternatives

- **Cloudflare named tunnel + Cloudflare Access** (SSO, stable hostname): run your own `cloudflared tunnel run` pointing at
  `http://127.0.0.1:5173`; keep `ACCESS_TOKEN` too (defence in depth). Add your hostname to `allowedHosts` in
  `frontend/vite.config.ts`.
- **Tailscale** (`tailscale serve 5173`): private to your tailnet; bind stays loopback.
- **LAN only**: not recommended (the app binds loopback by design); if you must, set `API_HOST`/Vite `host` yourself and
  set `LOCAL_TRUST=false`.

## Limits

Quick tunnels are for personal use, have no uptime guarantee and can take a minute for DNS. If the URL does not resolve
at first, wait or flush your DNS cache.
