# 3. Bullet rewrite

```
Rewrite these bullets for the role above: <bullets>.

For each one show: original, rewrite, pattern used (CAR / STAR + impact / action + adoption + operational impact),
why it is better, and a [TO CONFIRM] question for anything unverified.
Rules: Action + Scope + Technology + Impact; one achievement per bullet; 25-45 words; 1-2 metrics; 2-4 technologies;
strong verbs (architected, built, led, automated, reduced, standardized, shipped); never "responsible for/worked on/helped with";
keep before/after numbers and the word "estimated" where a baseline was estimated; never invent percentages;
do not upgrade my role ("contributed" must not become "architected").
Then audit your own rewrites for over-claims and correct them.
```
